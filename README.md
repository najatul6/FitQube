# 📖 About

FitQube is a full-stack MERN application built to deliver a complete digital fitness experience. The platform allows users to discover workout programs, connect with fitness trainers, manage memberships, and stay motivated with a modern, responsive, and user-friendly interface.

---

# ✨ Features

- 💪 Explore Workout Programs
- 🏋️ Browse Professional Trainers
- 📅 Membership & Fitness Session Booking
- 👤 Secure User Authentication
- 📊 Personalized Fitness Dashboard
- 📱 Fully Responsive Design
- ⚡ Fast & Optimized Performance
- 🔒 Protected Private Routes
- ☁️ Cloud Database Integration
- 🎨 Modern & Interactive User Interface

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/najatul6/FitQube.git
```

Move into the project

```bash
cd FitQube
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
